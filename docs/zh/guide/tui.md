# 终端界面

使用以下命令启动交互式终端界面：

```powershell
just dev
```

该界面是同一套扫描、盘点、规则、计划和执行契约的交互视图，不会创建独立的清理
策略。

## 用于复核

使用界面检查扫描结果、大小完整性、安全诊断、规则信息和选中的清理目标，再决定是否
执行保存计划。以运行中界面展示的按键提示为准，它们是当前构建的权威控制方式。

## 保持安全边界

界面不会让清理变成隐式行为。扫描和盘点仍然只观察。任何执行路径仍依赖有效计划、
已选目标，以及与 `clean --execute` 相同的实时授权检查。

如需脚本化或可审计流程，请用[扫描](/zh/guide/scan)保存 JSON，再按
[清理已保存计划](/zh/guide/clean)的流程操作。
