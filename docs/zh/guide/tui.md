# 终端界面

在交互式 stdin 与 stdout TTY 上直接运行 `devsweep` 即可打开终端界面：

```powershell
devsweep
```

在本仓库中：

```powershell
cargo run --locked --bin devsweep
```

没有 `tui` 子命令。`devsweep tui` 会被拒绝（退出码 2）。`just dev` 目前仍会传入
`tui`；该配方属于后续 release-contract 修复，不是现行教程。

该界面是同一套扫描、计划、规则和执行契约的交互视图，不会创建独立的清理策略。
直接运行要求 stdin 与 stdout 都是 TTY；重定向任一端会以 `tty_required` 退出码 2
结束。

## 用于复核

使用界面检查扫描结果、大小完整性、安全诊断、规则信息和选中的清理目标，再决定是否
执行保存计划。以运行中界面展示的按键提示为准，它们是当前构建的权威控制方式。

## 保持安全边界

界面不会让清理变成隐式行为。扫描仍然只观察。任何执行路径仍依赖有效计划、已选
目标、实时预览摘要，以及 `--confirm`（或界面内对应的确认）。

如需脚本化或可审计流程，请用[扫描](/zh/guide/scan)保存观察结果，再按
[清理已保存计划](/zh/guide/clean)的流程操作：精确选择、保存新计划、取得实时预览
摘要，然后确认。
