# 设计溯源

## 范围

本文说明 DevSweep 与其他公共清理工具，特别是 Mole（GPL-3.0）的关系。这不是法律建议。

## 立场

DevSweep 是基于 MIT 许可证的独立实现。

Mole 等公共工具启发了产品问题：识别高价值开发者缓存与构建产物、使不可逆工作明确化、
并优先使用可检查计划而不是静默修改。它们共享的是问题关注点，而不是实现材料。

## 未复制的内容

DevSweep 没有从 Mole 或其他第三方清理工具复制或轻度改写以下内容：

- 源代码；
- fixture 或 golden file；
- 规则表或提供方命令目录；
- 面向用户的文案或 UI 文本；
- 许可证文本或版权声明。

`.trellis/tasks/` 下的审计修复工作来自 DevSweep 自己的审计报告和不变量描述。

## 后续审查

如果未来改动引入从 GPL 许可作品派生的材料，应在合并前停止并重新评估许可证义务。独立
重新实现想法和安全要求本身不会改变 MIT 许可证基线。
