# GPUI 标题栏：明暗主题切换与设置入口

## 目标

在五个工作模式中，用户都能通过标题栏左侧的太阳／月亮按钮切换明暗外观，通过相邻的齿轮直接进入应用设置。截图中的租约横幅来自常亮操作；把图标画对只是第一步，输入行为也必须对应。

## 当前行为与范围

- 原生 GPUI 的 `desktop-gpui/src/view.rs:1183–1205` 分别绑定 `keep-screen-on`（太阳）和 `clean-screen`（显示器）。前者向系统申请 30 分钟常亮，后者显示可恢复的遮罩。F12 和 F11 分别有独立绑定（同文件 2453–2456）。
- 品牌菜单已有设置入口，渲染目标为 `Surface::Settings`（同文件 1384）。设置页已有即时预览、显式保存的主题选择（`desktop-gpui/src/view/page_support.rs:88–115,199–219`）。
- 本任务覆盖 GPUI 标题栏与随之失去入口的 GPUI 常亮逻辑。CLI/core 的常亮能力、Tauri、整页设置重设计、主题存储格式和系统配色检测均在范围外。独立的 F11 清屏与 Escape 恢复仍需可用。

## 需求与验收

- [x] **主题操作。** 在深色下显示太阳，点一次整窗切到浅色；在浅色下显示月亮，再点一次回到深色。当前模式、打开的页面和操作进度均保留。提示和辅助名称描述下一步动作，覆盖英文与简体中文。
- [x] **主题一致性。** 标题栏与设置页共享主题草稿。任一入口改动立即反映到另一处；与设置页一致，显式保存后重启恢复新主题，未保存退出后恢复上次保存值。用临时配置目录核实单击不会意外提交语言、缩放等其他草稿。
- [x] **兼容外观。** 从每种已有主题值进入，首次点击均按当前基础配色切到相反的显式 Light/Dark。高对比度下维持可读的系统配色，快捷按钮仍能往返修改基础偏好；正常毛玻璃与实色回退都随主题呈现。
- [x] **设置操作。** 齿轮一步进入与品牌菜单相同的设置页；重复点击仍停在该页。返回当前工作模式时保留其状态，例如 Note 输入。品牌菜单/F10 入口、F11 遮罩与恢复行为通过回归检查。
- [x] **电源副作用。** 两个按钮和原 F12 入口均不能创建或停止常亮租约；主窗口不再显示该功能的 token/owner/剩余时间横幅。保留其他通知，验证时无需调用真实电源服务。
- [x] **原生可操作性。** 两个按钮支持鼠标、键盘焦点和激活、Windows UI Automation；齿轮作为普通按钮报告，辅助名称、可见焦点与实际动作一致。宽窄布局下与系统窗口按钮的点击区分开。
