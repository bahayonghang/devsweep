# GPUI 轻盈毛玻璃：设计契约、Token 与外壳排版

父任务：[11-12-gpui-mole-parity-airy-glass](../11-12-gpui-mole-parity-airy-glass/prd.md)。差距编号 S1–S10 见父任务 `research/gap-analysis.md` 第 4 节。

## 目标

打开 DevSweep 看到的是明亮场色上的一张纸。内容区是实色，字号和间距成刻度，每个模式页的第一行就是状态、数字和下一步动作。只改 `desktop-gpui`，不改 core、CLI、Tauri 和 TUI。

其余界面子任务都建立在这里的 Token 和外壳上，所以它最先实施。

## 需求

| 编号 | 需求 | 差距 |
| --- | --- | --- |
| R1 契约 | 把父任务 `research/DESIGN.md` 放到 `desktop-gpui/DESIGN.md`。`ui.rs` 的每个颜色、字号、间距、圆角 Token 都能在该文件里找到同值。有意偏离写进 customized 行。 | S10 |
| R2 刻度 | 字号四档（2 / 1 / 0.875 / 0.75rem），间距六档（0.5 / 0.75 / 1 / 1.5 / 2 / 3rem），圆角四档（20px、16px、12px、胶囊），复选框 4px。视图代码只引用 `ui.rs` 的具名 Token。 | S2 |
| R3 材质 | 浅色场在任何桌面背景上都保持明亮。纸是唯一的半透明层，带一条阴影。卡片、行、指标格用实色填充，普通对比度下没有描边。 | S3、S4 |
| R4 排版 | 去掉模式页的图标块、大标题和副标题，首行改为状态、数字、动作。纸占满窗口高度，列表在纸内滚动。模式标签在 720 逻辑像素以上始终带文字。 | S1、S5、S6 |
| R5 主题 | 设置提供浅色、深色、跟随系统三项，`system` 跟随 Windows 应用模式。其余存量值的映射不变，首次启动仍是深色。保存的主题、字体和文字缩放不丢。 | S7 |

## 验收

- AC1（R1）：`desktop-gpui/DESIGN.md` 存在，带 provenance、palette、customized 三行注释。`ui.rs` 里浅色与深色的每个颜色 Token 在该文件里有同值条目。
- AC2（R2）：新增的源码守卫测试通过：`view.rs` 和 `view/*.rs` 里不再出现 `.text_size(rems(`、`.rounded(rems(`、`.rounded(px(` 字面量，间距取值都在六档之内。基线是 19 种字号、13 种圆角、23 种间距。
- AC3（R4）：英文与中文、浅色与深色、100% 与 125% 文字缩放、默认窗口（1080×720）与宽窗口（1350 以上）各截一组五个模式的首屏。每张图第一行能读到状态和主动作，没有页面标题；五个标签的文字都可见。
- AC4（R3）：浅色主题窗口先后放在纯黑和纯白的受控背景上，场色采样点的相对亮度都不低于 0.70，纸面正文对比度不低于 4.5:1，焦点环和必要边界不低于 3:1。深色主题同样测正文和焦点。
- AC5（R3）：关闭 Windows 透明效果、窗口宽度小于 960、设置 `GPUI_DISABLE_DIRECT_COMPOSITION=1` 三种情形都是实色，布局和命中区域不变。
- AC6（R5）：选"跟随系统"后切换 Windows 应用模式，窗口不重启即跟随。旧偏好文件读入再保存，未知字段和其他字段不变。
- AC7（R6）：Tab、Shift+Tab、Alt+←/→、F10、Enter、Space、Escape 行为不变。模式标签仍是 `Role::Tab` 加 `aria_selected`，不使用 active descendant。开启 UIA 的 debug 构建里逐个点击标签（含已选中的）不崩溃。
- AC8（R7）：Clean 审阅行、Analyze 位置卡和面包屑不显示 `\\?\`，盘符为大写。中文界面的 Software 摘要行是中文。
- AC9：`just gpui` 与 `just ci` 通过。现有对比度单元测试覆盖调整后的 Token。

## 不在范围

新功能和新的后端调用。行星、插画和诗句。捆绑 Figtree 或其他字体。过渡动画。Tauri 与 TUI 的样式。偏好文件格式。

## 已定事项

- 颜色方案沿用 `mint`，与现有 `ui.rs` 的浅色值一致。
- 深色组沿用 `ui.rs` 现值，父任务 `research/DESIGN.md` 记有 2026-11-12 的对比度测量。
- 原生背板的取舍按 AC4 的测量自动决定：达标则保留着色背板，不达标则场色不透明。不需要再做主观选择。
