# Software：清单证据、图标与列表体验

父任务：[11-12-gpui-mole-parity-airy-glass](../../../11-12-gpui-mole-parity-airy-glass/prd.md)。差距编号 W1、W2 见父任务 `research/gap-analysis.md`。

## 目标

在软件列表里一眼认出每个应用：真实图标、版本和发布者、容量、安装日期，并能按这些排序和筛选。缺少的证据先在 core 和 CLI 补上。全程只读，不执行任何卸载、更新或启动项变更。

## 需求

| 编号 | 层 | 需求 | 差距 |
| --- | --- | --- | --- |
| R1 | core | 清单条目增加可选的图标位置证据和安装日期证据。不读取、不输出卸载命令字段。 | W1 |
| R2 | CLI | `software inventory --format json` 带上新字段；人类可读输出显示安装日期，中英文。 | W1 |
| R3 | GPUI | 行首显示真实图标；取不到时用字母头像。取图不执行文件、不访问网络路径、不阻塞列表。 | W1 |
| R4 | GPUI | 行内容：名称、版本 · 发布者、容量（带证据限定，未知写未知）、安装日期、可读的来源名称。 | W1 |
| R5 | GPUI | 排序：名称、容量、安装日期。筛选：来源、可处理性。与搜索可叠加。 | W2 |
| R6 | GPUI | 对选中的应用只读地查看残留。前提是 core 的发现接口能在卸载前调用；否则移交 host-actions。 | — |

## 验收

- AC1（R1）：core 夹具测试覆盖图标与日期的有值、缺失、格式错误。格式错误得到空值，不报错、不猜。
- AC2（R1）：新增字段里没有任何卸载命令内容；有测试断言。
- AC3（R2）：CLI 契约测试覆盖新字段；旧字段名称与含义不变。
- AC4（R3）：在本机真实清单上，列表文字先出现，图标随后到达；滚动不卡顿。图标路径指向不存在的文件或网络路径时显示字母头像。
- AC5（R4、R5）：中文界面的行和摘要全部为中文，看不到 `arp:CurrentUser:Registry64` 这类内部 ID。按安装日期排序时无日期的条目在最后。
- AC6（R6）：残留预览不产生任何计划或写入；或者在 `research/contract.md` 里写明移交原因。
- AC7：`just ci` 与 `just gpui` 通过。英文与中文原生截图各一组。

## 不在范围

卸载、更新、启动项和残留的执行（属于 host-actions）。从网络获取图标。应用评分或使用频率推断。

## 依赖

界面部分在 airy-glass-shell 之后。core 与 CLI 部分可以先做。
