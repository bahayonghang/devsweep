# R8 实施与验收

2026-11-20，集成工作树 `D:/ds-integrate-1120`，基础版本为本地 `264e7ac` 与远端 `324e72b`。

| 验收 | 结果 |
| --- | --- |
| AC1 有序摘要 | `MaintenancePlanV2` 只接收互不重复的 Execute 行。测试覆盖空计划、未知或错误类别、重复、重排与增删。整批摘要纳入每项的实时就绪或跳过原因与身份。独立审查发现失效启动项仅凭旧单项摘要不能识别同名目标变化；复验 V2 的目标与备份绑定见独立检查。 |
| AC2 V1 | CLI 读取旧单项 JSON，单个 `--operation` 仍写 V1。定向套件覆盖原单项 DNS 假执行、设置跳转结果为 Launched、只读与不合格项拒绝、V1 审计恢复和确认要求。 |
| AC3 CLI | 真实 CLI 的反复参数按原顺序保存 V2，缺摘要或确认返回 2，重复及指引被拒。用相同解析器和输出路径加固定适配器运行三项，验证按原顺序返回 failed、skipped、succeeded 且处理器返回失败退出类别。CLI 输出文件沿用只新建契约。 |
| AC4 默认与界面 | 七个可执行项初始全不勾。鼠标、键盘和 UIA 均可操作，有单独的审阅与确认控件。11 个系统设置和指引在折叠区，无法加入批次。磁盘健康显示为只读。 |
| AC5 执行与历史 | 两种语言均实测一份混合计划。每项一个运行 ID，共用批次 ID。History 以两种 ID 都能查看。运行中显示当前项目，取消令牌只在项目之间检查。原生窗口的结果与真实隔离审计核对，见[原生记录](../evidence/native/acceptance.md)。 |
| AC6 权限与重检 | 预览拒绝的项保持跳过。测试执行器模拟预览后资格变化、已拒绝项变得可用及程序身份改变，全部零派发。真实窗口显示“需要管理员权限”及其英文对应文案。 |
| AC7 门禁与原图 | 根整合门禁 940 项通过、3 项忽略，Python 23 项通过。双语审阅、结果、UIA 和 CLI 同批历史见原生记录。普通 GPUI 复验 262 个主程序及 4 个画廊测试通过、2 个 opt-in 用例忽略。最终 `just gpui` 以及独立复核由主会话记录。 |

首次桌面全套发现一条旧断言期望在未绑定宿主执行器的会话按一次 Enter 即进行提权预检。更新后断言第一次、第二次 Enter 分别勾选和取消，队列为空。权限提示在显式审阅后通过三项夹具及双语原生 UIA 验证。原生检查发现审阅和结果行的可读名称缺失，已补相应角色、编号和逐行状态原因。
