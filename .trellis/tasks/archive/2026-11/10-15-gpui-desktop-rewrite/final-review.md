# 最终实施方案审阅

日期：2026-10-15。范围已收敛，待本摘要审阅通过后进入实施。

## 目标与已确认决策

首版面向 Windows x64，以 GPUI + Rust 重写 DevSweep Desktop，同时保留现有
CLI 的跨平台支持。共享 Rust 核心提供实际功能，CLI 先验收，界面负责呈现与操作。
Windows 专属新增能力在其他平台明确报告不支持，不破坏现有命令。

## 本期范围

- 完善清理、软件卸载/更新/启动项/残留、优化、磁盘分析、状态与进程五类功能。
- 补充 Claude Code、Codex、Cursor 的缓存、旧版本、会话、worktree 分类；敏感
  数据需要单独选择、活动状态核验及可验证恢复。工具卸载交由 Software 提供程序。
- 采用最新兼容稳定依赖；GPUI 必要时选择最新上游的已验证固定提交，明确 Rust
  工具链/MSRV 变更及旧版本例外，保持可复现构建。
- 复用 DevSweep 图标及有授权的本地资产，提供五类原生工作台、设置与托盘；保留
  中英文、中文输入法、键盘、DPI、无障碍和减少动画支持。

## 不包含

首版不同时交付 macOS/Linux/Windows ARM64 原生桌面；不复制 Mole 品牌资产；
不引入永久文件删除、Cargo home 清理、Docker 清理或任意系统脚本。保留 Tauri
作为对照和回退；切换默认、移除旧版、安装、签名、发布与提交另行处理。

## 实施顺序

沿用既有 1 个父任务及 16 个子任务：先 C16 依赖/工具链，再 C01 CLI 契约，
随后按依赖完成 C02–C08 与 C15 功能。C09 在 CLI 契约就绪后尽早验证 GPUI 原生
可行性；C10–C13 接入已验收能力；C14 汇总兼容、性能、原生验证和迁移证据。
每个子任务均有独立 PRD、设计、实施清单和 implement/check 上下文。

## 验收与性能目标

- 相同输入下 CLI/GPUI 的报告、选择、预览摘要、拒绝原因及结果一致；写操作遵守
  计划、实时预览、确认和审计契约，恢复与有限保持亮屏会话遵守各自契约。
- 保留现有 Windows/Linux/macOS CLI 检查；Windows x64 原生验证覆盖离线包、
  中文输入、UIA、设置迁移、生命周期、五类工作流及失败/取消状态。
- 冷启动 p95 ≤ 1.5 秒且 ≤ 同条件 Tauri 的 80%；交互响应 p95 ≤ 100 ms；
  空闲私有内存 ≤ 200 MiB 且 ≤ Tauri 的 70%；完整软件清单 p95 ≤ 5 秒。
- 其余帧间隔、CPU、核心扫描、取消和 20 次生命周期目标，以及样本/基线方法，
  按[完整性能协议](research/performance-protocol.md)一并审阅。通过后冻结预算，
  不因未通过而降低阈值，不用少扫描或漏报换取速度。

## 风险、技术后续与当前状态

GPUI 具体版本/提交及工具链由 C16/C09 以实施当时证据选定；Windows 原生输入、
无障碍、图形和性能必须实测。提权、卸载、AI 数据恢复和传感器支持均有独立验收，
不确定的提供程序保留明确能力缺口，不宣称完成。换工具包并不保证后端查询变快。

平台范围已经用户确认，PRD 收敛已完成，无待定产品问题。任务仍为 planning，
产品验收均为 NOT_RUN；本轮未更改产品代码或依赖。此摘要通过后从 C16 开始，
不再重复询问平台范围。
