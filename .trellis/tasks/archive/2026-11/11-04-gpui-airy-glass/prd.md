# GPUI 桌面界面轻盈毛玻璃重构

## 目标与范围

打开 DevSweep 后，用户能看出当前模式、正在查看的数据和下一步可执行的操作。在长列表中，路径、容量、风险和确认条件始终清楚。以 design-atlas 的 `style:airy-glass` 统一 Windows GPUI 工作台。用户已确认首次启动继续使用深色，深色和浅色同等交付，保留已保存的主题选择。

涵盖顶栏与窗口按钮、模式导航、菜单、底部状态栏、Clean、Software、Optimize、Analyze、Status，以及设置、历史、保护和规则等现有辅助页面。覆盖这些页面的输入、筛选、列表、图表图例、横幅、空态、错误、预览和确认态。保留现有页面、快捷键、文字缩放、语言和安全流程。Tauri、TUI、托盘系统菜单、安装包和历史功能验收缺口另行管理。

## 要求与验收

| 编号 | 用户可见的结果 | 验收场景 |
| --- | --- | --- |
| R1 材质 | 浅色为薄荷至淡紫底场、透光纸面、实色内容区。深色以低饱和冷色底场和烟色纸面形成同样的层次。边缘透出底色，表格、正文和警告有稳定底色。 | 默认首次启动截图呈现深色，切换浅色并重启能恢复选择。两套主题各用同一 Clean 审阅数据对照，能辨认底场、主面和数据行三个层次。 |
| R2 导航 | 一眼能分清当前模式、键盘焦点和普通标签。分段筛选与顶层导航有层级差异。只读状态标签和可点击按钮即使同为胶囊形也能区分。 | 在当前标签仍选中时把焦点移到另一标签，二者均可辨。用 Tab、Shift+Tab、已有模式快捷键与菜单完成往返，开启 Windows UIA 后也能读出名称、角色和选中状态。只读标签不进入 Tab 序列。 |
| R3 动作 | 主要、次要、图标、危险操作具有清楚的优先级。默认、悬停、按下、焦点、禁用和适用时的忙碌态可区分。危险动作和失败信息有文字或图标提示。 | 在 Clean 选中目标、请求预览、进入确认再取消。禁用操作不可触发；选择失效后不能沿用旧确认。用同一组夹具核对 Software / Optimize 的只读、警告与危险状态。 |
| R4 内容 | 使用字重、对齐和间距组织信息。长路径与软件名可辨，容量数字对齐，状态刷新不会挤走操作。列表、输入和图表图例不叠加模糊。 | 五个主模式及辅助入口逐页核对。中文和英文、100% 和 125% 文字缩放、默认窗口和可调整到的窄窗口分别抽查；关键操作可达，滚动、表格及输入焦点正常。 |
| R5 无障碍与回退 | 高对比、系统关闭透明效果、无法使用原生材质或窗口宽度小于 960 个逻辑像素时使用稳定实色。减少动态效果时去掉装饰动效。 | 对两套主题的实际合成底色测量：普通正文及次要文字至少 4.5:1，可操作控件的必要边界和可见焦点至少 3:1。验证高对比的文字、焦点、选中和危险状态；关闭透明后仍能区分导航、操作和内容。 |
| R6 原生质量 | 鼠标、键盘、UIA、窗口拖动和标题栏按钮延续既有行为。材质不引入持续装饰重绘。 | 同机同数据记录前后截图与操作样本，覆盖列表滚动、切换模式、窗口最大化／还原和空闲。交付记录区分原生模糊与实色回退、自动化结果与实机观察，未测项标明原因。 |
