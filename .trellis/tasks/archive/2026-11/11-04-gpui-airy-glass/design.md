# 原生界面设计

## 材质与主题

`research/DESIGN.md` 是 design-atlas 生成的浅色原始条目。项目根目录的 `design.md` 记录产品架构。以下是 GPUI 专用适配，尤其适用于默认深色主题。

| 角色 | 浅色 | 深色设计起点 |
| --- | --- | --- |
| 静态底场 | 薄荷 #E7F6F1 到淡紫 #EDE7F8 | 墨青 #142322 到灰紫 #232032 |
| 主工作面 | 白色约 78%，单层亮边、轻阴影 | 烟灰 #20292F 约 90%，低亮度冷灰边；与底场通过明度分层 |
| 内容区与文字 | 实色近白；主文 #24303A、次文 #5C6B76 | 实色 #252F36；主文 #EDF4F2、次文 #B3C2BF |
| 输入、完成／输出、结果 | 深绿 #187A56／紫 #6D4BD6 | 薄荷 #87D9BA／淡紫 #C6B5FF；危险、警告沿用独立语义 |

深色值为待上机验证的候选。按真实合成背景校准两套色值。高对比优先沿用 HIGH_CONTRAST，焦点环与选中填充分开。保留现有图表分类色和图例，不把多类别压成绿紫两类。

主工作面借鉴 20px 外圆角和一条轻边；内部列表靠对齐、分隔和实色承载密度。主动作实心、次动作弱填充、危险动作有明确动词；状态徽标尺寸更紧，无悬停或按压反馈。导航选中用填充和字重，键盘焦点用独立 2px 环。沿用已安装字体偏好和 rem 缩放，数字优先等宽对齐。空间取 8 / 12 / 16 / 24 逻辑像素节奏，先为长路径与状态列留宽。

## 原生边界与兼容

- 在 `desktop-gpui/src/ui.rs` 扩展现有 Theme 和纯组件，复用 button、icon_button、badge、segment、KeyboardFocus、list_row、banner。材质分为窗口底场、主工作面和实色内容区。card 的调用有嵌套，迁移前先标出顶层主面，避免所有 card 同时透光。
- `view.rs` 的 ShellView 和 WindowOptions 拥有窗口合成、标题栏及路由。Windows 后端 `vendor/gpui_windows/src/window.rs` 已处理 Blurred 和 MicaBackdrop，但它们作用于整窗。先用现有 API 做同屏 A/B，验证根背景没有盖住效果。设计稿的 20px 纸面模糊是视觉参考，不能作为 Windows 局部模糊能力的证明。优先在受支持的 Windows 上交付可观察的原生效果；如果做不到，记录阻塞，单独验收实色回退。
- 高对比优先，其次判断系统透明设置、窗口能力和逻辑宽度。关闭材质时保持布局、层次和命中区域。减少动态效果单独处理。保留 DesktopPreferences 的默认 Dark、已有序列化值和主题映射；各页读取同一 Theme。
- 页面只绑定现有状态和操作。保留稳定元素 ID、真实焦点、Role::Tab、选中语义、UIA 调用与 Windows 标题栏命中测试。焦点控件不能给自身设置 active descendant。清理预览摘要、确认和执行仍由原有状态机控制。
- 回退顺序为先关闭原生材质，保留可读的实色主题和控件；再按共享组件或页面批次回退。历史归档中尚未取得的性能、实机及打包证据单独列账。
