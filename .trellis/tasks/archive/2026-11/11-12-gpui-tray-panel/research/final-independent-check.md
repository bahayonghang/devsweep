## 复核修正

- Status 页的趋势缓存在有托盘订阅时仍追加，即使主页面已暂停。这会回退 R2 AC5。修改后托盘继续读取最新发布的快照，暂停只冻结主页面趋势。新增的 Session 回归在集成测试二进制中通过。
- history totals 原先对截断日志写出 partial JSON，却返回成功退出码。按现有 CLI 的 partial 约定，现在人类可读和 JSON 路径都先输出可用统计，再返回 5。完整统计继续返回 0。新增双语黑盒退出码断言，并用同一份截断的 R8 夹具复验。独立 CLI 构建及该契约通过，修改文件通过 rustfmt 与 git diff --check。
