# Design - Software Delivery Gate

`software-inventory-plan` freezes tagged identities, fingerprints, eligibility,
and preview DTOs. `software-execution-audit` may reconstruct strategies only from
those validated identities and owns outcome/audit schemas. The presentation
child consumes both contracts and owns no installer command parsing.

The umbrella fixture ledger covers registry 32/64 views, current-user/machine
MSI as manual-only, current-user MSIX, duplicates without fuzzy merging, stale
removal/version change, corrupt/denied source, durable dispatch/restart and the
five execution terminals, and redaction. The mode
is registered only after native standard-user/no-UAC evidence. Rollback disables
the entire Software registration while preserving versioned audit records.
