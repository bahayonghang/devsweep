in the runtime child's `evidence/native-precheck.md`; it is not a passing

  It does not replace the immutable Tauri invoke function or synthesize a report.
- The CLI scans the same fixture roots with the launch's isolated app data.
  Equality compares the entire core report without removing fields.
- No preview, execute, trash move, external cleanup or user-cache scan occurs.
